# المشكلات المعروفة والمنقوص

- الكود غير مبني وغير مختبر؛ قد تظهر أخطاء أنواع أو تبعيات عند أول تشغيل. CI يستخدم `npm install` لعدم وجود lockfile؛ بدّله بـ `npm ci` بعد توليد `package-lock.json`.
- الذهب (iSagha) والصناديق (SNDUK) لهما adapters وهو غير مختبر على الصفحة الحية ومعتمد على شكل الصفحة الحالي؛ باقي المصادر بلا adapters.
- لا رسوم بيانية (لم يُضف Recharts) ولا WebSocket/بث: يلزم مزود يدعمه.
- «lint» حاليًا فحص TypeScript فقط (لا ESLint).
- PWA: manifest فقط، بدون service worker، فلا عمل دون اتصال.
- لا قاعدة بيانات ولا Redis ولا مستخدمين؛ المحفظة والمفضلة والتنبيهات في localStorage.
- التنبيهات تُقيَّم أثناء فتح صفحتها فقط، بلا إشعارات.
- المحفظة: لا توزيع أصول ولا أداء عبر الزمن؛ السعر الحالي يدوي.
- لا مقارنة شهادات متعددة ولا مقارنة أسعار البنوك (تحتاج بيانات).
- لا اختبارات واجهة (RTL/تنقل) ولا Playwright.
- لا أيقونات Android، ولا عنوان خادم مطلق للـ APK.
- Rate limiting مفعّل بحد عام للخادم فقط.
- لم يُضف ترخيص.
- محلل SNDUK مبني على صفحة صندوق واحد ونص ظاهر؛ قد لا تتطابق باقي الصفحات (صناديق بلا عوائد أو بتنسيق مختلف). يُترك الحقل فارغًا بدل التخمين.
- لا تاريخ/رسم لقيم الوثائق، ولا «العائد منذ بداية العام».
- الوضع المباشر (`src/services/direct.ts`) يعمل داخل Android فقط؛ في المتصفح يلزم الخادم بسبب CORS. لم يُختبر على جهاز، ولا يُعرف سلوك CapacitorHttp مع كل الاستجابات.
- في الوضع المباشر لا يوجد Rate limiting مشترك: كل هاتف يجلب لنفسه.
